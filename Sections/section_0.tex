These notes come in two forms, 
\begin{itemize}
    \item \ifcsname insertBlanks\endcsname\textbf{[This version].}$\;$\fi

    \item \ifcsname insertBlanks\endcsname\else\textbf{[This version].}$\;$\fi

\subsection{AI use declaration}

Generative AI (Microsoft Copilot) has been used to
\begin{itemize}
    \item Transcribe the course slide deck into a first draft of these course notes, which were subsequently extensively edited manually.
    \item Generate the javascript scripts for interactive visualisations.
    \item Cross-check the final PDF version for errors or inconsistencies.
\end{itemize}
Otherwise, all course unit materials including the mathematical content, examples, diagrams, slides, tutorial questions, online quizzes, \textit{etc.} were created by humans (\textit{i.e.} the current and previous course unit leads).
